What is ScholarWatch?

ScholarWatch monitors Google Scholar for new publications matching your keywords and posts notifications directly to your Discord channels. Set up multiple watch channels, each with their own keyword list, to organize your monitoring by topic.

Quick Start

  • Set your SerpApi key with /watch apikey set
  • Add a watch channel with /watch channel add #channel
  • Add keywords with /keywords
  • Enable the watch with /watch toggle

See the full setup guide for details.

Features

  • Multiple watch channels per server with independent keywords
  • Flexible scheduling (daily hour or custom cron)
  • Google Scholar search syntax support
  • English and French language support
  • Self-hostable with Docker
